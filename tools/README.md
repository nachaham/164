# 드로잉 연습 도구

별도 설치 없이 HTML 파일을 브라우저(Chrome, Safari, Firefox 등)로 열면 바로 동작합니다.
모든 이미지는 브라우저 메모리에서만 쓰이며 어디에도 업로드되지 않습니다. 모바일에서도 사용할 수 있습니다.

## timer.html — 제스처 드로잉 타이머

1. 파일을 더블클릭하거나 브라우저로 끌어다 엽니다.
2. 참고 이미지를 여러 장 끌어다 놓거나 "이미지 선택"으로 고릅니다.
3. 간격(30초 / 1분 / 2분 / 5분 / 10분 / 직접 입력 초)을 고릅니다.
4. 필요하면 "매 N장마다 쉬는 시간"을 설정합니다. N이 0이면 쉬는 시간이 없습니다.
5. 섞기, 좌우반전, 흑백, 알림음을 고르고 "시작"을 누릅니다.

화면에는 큰 카운트다운, 진행 막대, `n / 전체`, 세션 총 경과 시간이 표시됩니다.
이미지가 바뀔 때 짧은 알림음이 납니다.
설정은 브라우저 localStorage에 저장됩니다. 저장이 막힌 환경에서는 저장 없이 동작합니다.

| 키 | 동작 |
|---|---|
| Space | 일시정지 / 계속 |
| → | 다음 장 |
| ← | 이전 장 |
| F | 좌우반전 |
| G | 흑백 |

## compare.html — 원본·모작 비교 도구

1. "원본"과 "내 그림" 칸에 각각 이미지를 불러옵니다.
2. 보기 모드를 고릅니다.
   - 나란히: 두 그림을 옆에(좁은 화면에서는 위아래로) 배치
   - 겹치기: 내 그림을 원본 위에 투명도(0~100%)로 겹침
   - 슬라이더: 분할선 기준으로 왼쪽은 원본, 오른쪽은 내 그림
   - 번갈아: 원본과 내 그림을 전환. "자동 깜빡임"은 0.5초마다 전환
3. 보조선(두 그림에 동시에 적용)
   - 격자: 3×3부터 12×12까지 비율 격자
   - 3분할: 삼등분선
   - 가이드선: "가이드선 추가"를 켜고 그림을 클릭하면 가로선이 생깁니다(눈 위치, 턱선 등). 선 근처를 다시 클릭하면 지워지고, "선 지우기"로 전부 지울 수 있습니다.
4. 그림별 조절: 크기, 가로/세로 이동(두 그림 맞추기), 좌우반전, 흑백, 톤 분리(2/3/4톤, 명암 덩어리 비교).
5. 오른쪽(모바일에서는 아래) 패널에 RULEBOOK 분류(두상·얼굴, 신체, 선, 명암, 색, 구도)별 메모를 적습니다.
   "메모 복사"를 누르면 마크다운으로 클립보드에 복사되므로 `log/`에 붙여넣으면 됩니다.
   메모는 브라우저 localStorage에도 임시 저장됩니다. 새로고침 후에도 남지만 이미지는 남지 않습니다.

| 키 | 동작 |
|---|---|
| 1 / 2 / 3 / 4 | 나란히 / 겹치기 / 슬라이더 / 번갈아 |
| G | 격자 켜기/끄기 |
| B | 번갈아 보기 전환 |

## 참고 사항

- `file://`로 열어도 되도록 외부 라이브러리와 네트워크를 쓰지 않습니다.
- 클립보드 복사는 브라우저 정책에 따라 실패할 수 있으며, 이 경우 보조 방식으로 다시 시도합니다.
- 알림음은 첫 "시작" 클릭 이후부터 브라우저에서 허용됩니다.
