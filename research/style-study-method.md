# 특정 작가 그림체 학습 방법 (모작 / 응용 / 기초 병행)

- 작성일: 2026-11-07
- 대상: 일러스트·애니·만화풍 작가(한국/일본 일러스트레이터 계열) 그림체를 강의(oridays)를 따라가며 학습
- 근거 표기: **[출처]** = 아래 Sources에서 확인한 내용, **[제안]** = 출처 내용을 바탕으로 한 작성자의 설계(검증된 수치 아님)
- 한계: 웹 검색으로 "작가 그림체를 수치로 분해하는" 단일 권위 있는 방법론은 찾지 못했다. 특히 Proko 에피소드 본문(트랜스크립트), Drawabox 공식 본문, 코로소/클래스101 커리큘럼 상세는 접근 불가였다. 비율(%)은 출처가 직접 제시한 것이 아니라 **[제안]**이다.

## 1. 그림체 해체 절차 (순서와 측정 방법)

핵심 원칙: **모작(복제)이 아니라 연구(study)**. 복제는 원본의 과정과 재료를 반복하는 것이고, 연구는 작가의 사고(왜 그렇게 그렸는가)를 최대한 뽑아내는 것이다 [출처: Proko S2E17 소개문, Classical U Lesson 11]. 한 번에 한 가지 측면(선, 색, 구도 중 하나)에만 집중하고, 자기 수준에서 배울 수 있는 작은 부분만 가져온다 [출처: Proko Line Master Studies critique].

### 0단계. 레퍼런스 선정 (모작 전)
- 같은 작가의 작품 **3~5장 이상**, 가능하면 정면/측면/3/4 얼굴, 상반신, 전신이 섞이게 고른다. 여러 작품을 비교할수록 안정적인 규칙과 우연한 변주를 구분할 수 있다 [출처: 형식분석 자료의 "여러 작품 비교" 권고, 일반 원칙].
- 처음에는 **선화 위주 또는 단순한 작품**부터. Proko 과제도 선만 보이는 단순한 원본을 권한다 [출처: Proko].
- 출처(작가명, 원본 링크)를 기록하고, 결과물을 본인 작품으로 공개하지 않는다 [출처: seaglassdraws "DO NOT CLAIM THE FINAL AS YOUR OWN"].

### 1단계. 눈으로 먼저 분석 (그리기 전, 5~10분) — 측정용 오버레이
레퍼런스 위에 투명 레이어로 다음 보조선을 직접 그어 **수치를 적는다**.
1. 화면을 가로세로 3분할해 인물의 위치·크기를 잡는다 [출처: Clip Studio 모사 기사].
2. **두상**: 머리 전체 높이를 1로 두고 눈 중심선의 위치(예: 0.5보다 아래/위), 코끝, 입, 턱 끝의 높이 비율. 눈 위치가 머리 절반보다 높은가 낮은가는 나이감과 직결 [출처: 아니메 사주쿠류 책 메모(scrapbox), 개인 메모라 신뢰도 중간].
3. **눈**: 눈 가로 폭을 "눈 1개 폭"으로 삼아 눈 사이 간격이 몇 배인지, 눈 높이/폭 비, 홍채가 눈꺼풀에 가려지는 비율.
4. **얼굴 대 머리**: 얼굴 면적(눈썹~턱) 대 머리카락 포함 실루엣 비율. 머리 폭 대비 턱 폭.
5. **신체**: 등신(머리 높이 기준), 어깨폭/머리폭, 손 크기/얼굴 크기.
6. 파트 간 **상대 비율**을 기록한다. 초보 모작은 파트 비율·위치가 원본에서 어긋나는 경우가 많다는 연구 보고가 있다 [출처: 오사카교육대 부속 고교 연구 포스터, IPSJ 자료 검색 요약].

### 2단계. 선 분석
- 외곽선/내부선 굵기비를 **픽셀 또는 상대값**으로 기록(예: 외곽 3 : 내부 1.5).
- "왜 이 위치에서 굵은가"를 묻는다: 하중을 받는 쪽, 그림자 쪽, 겹침 부분 등 [출처: Proko Line Master Studies critique의 "왜 여기 선이 굵은가" 질문].
- 선 끝(입/출), 끊기는 위치(턱, 머리카락 끝), 이어지는 위치를 확대해 기록.
- 형식분석 질문 재사용: 섬세/굵음, 유려/끊김, 정밀/스케치풍 [출처: 형식분석 자료 요약].

### 3단계. 형태 단순화 공식 추출
- 선이 만드는 **면을 도형으로 인식**하고 [출처: Clip Studio 모사 기사], 눈·코·입·손·머리카락 덩어리를 각각 "원/삼각형/사각형 중 무엇으로 환원되는가"로 기록. 지배적 도형이 무엇인지 확인 [출처: 형식분석 자료].
- 작가가 **생략하는 것**(코 윤곽, 손가락 관절, 속눈썹 개수 등)을 목록화. 단순화 공식 = "무엇을 남기고 무엇을 지우는가". [출처: Clip Studio의 "주요 디테일만 추출하여 단순화"; 나머지 구체화는 제안]

### 4단계. 명암·색 분석
- 명암 단계 수(2/3/4단), 경계(셀/번짐/혼합), 그림자 색상 이동(채도·색상 변화 방향).
- 색은 **스포이트 금지, 눈으로 맞춘 뒤 색상환 위치를 기록** [출처: seaglassdraws]. 단, 나중에 정답 확인용으로 스포이트를 쓰는 것은 [제안].
- 팔레트: 한정 색인가, 유사색/보색 중 무엇인가, 항상 주조색인 색과 포인트색 구분 [출처: 형식분석 자료].
- 채도 관계(피부 vs 옷 vs 배경)를 수치(HSV의 S)로 기록 [제안].

### 5단계. 모작 (규칙을 확인하며 그리기)
1. 보조선(3분할/십자선)으로 비율을 먼저 잡고, 외형부터, 디테일은 마지막에 [출처: Clip Studio 모사].
2. 원본을 **뒤집어 그리기**로 인상이 아닌 형태를 보게 한다 [출처: Clip Studio 모사 기사].
3. 그린 뒤 **원본에 겹쳐 비교**(투명도 50%)해 어긋난 곳을 찾고, 서툰 부분만 집중 재모작 [출처: Clip Studio "서투른 곳만 집중 모사"].
4. 어긋난 항목을 RULEBOOK의 "자주 틀리는 항목"에 추가.

### 6단계. 규칙 검증 — "새 그림으로 테스트"
- 규칙서만 보고(원본 없이) **원본에 없는 포즈/각도**를 한 장 그리고, 원본 옆에 두고 "같은 작가처럼 보이는가" 체크. 이것이 응용작의 역할이다 (아래 2장).
- 이 단계에서 틀린 규칙을 수정하고 규칙서 버전을 올린다.

### 7단계. 반복
같은 원본을 다른 각도/매체로 다시 보라는 권고 [출처: seaglassdraws]. 규칙 하나 수정 → 같은 레퍼런스 재모작 → 응용작으로 재검증.

## 2. 주간 배분 (모작 / 응용 / 기초)

출처가 직접 제시한 비율은 없다. 다만 다음 근거가 있다.
- 모작에서 끝내지 말고 **배운 것을 자기 작품에 적용**해야 한다 [출처: seaglassdraws "Stopping at the copy" 실패 항목, Clip Studio의 모사→응용 구성].
- Drawabox는 **50% 규칙**(학습/연습 50%, 목적 없이 그리는 시간 50%)을 둔다 [출처: Drawabox 커뮤니티/Lesson 0 요약]. 학습과 자유 작업을 분리해 번아웃·두려움을 줄이는 취지.
- 기초와 개인 작업 사이에서 적용이 안 되는 혼란은 정상이라는 증언 [출처: Drawabox 커뮤니티].

### 권장 (강의 수강 중, 주 5~6일 기준) [제안]

| 구분 | 비중 | 내용 | 근거 |
|---|---|---|---|
| 강의 과제 + 기초 연습 | 40% | oridays 회차 과제, 비율·형태·해부 드릴(얼굴/손 단독 드릴) | 강의 진도 유지, 기초가 모작의 정확도를 결정(Proko: 정확한 비율이 작가의 선택을 이해하게 함) |
| 모작(분석 포함) | 25% | 레퍼런스 1~2장을 위 1~5단계로 | 분석+모작이 규칙서를 채움. 너무 많으면 복제만 반복 |
| 응용작(작가 규칙으로 새 그림) | 25% | 해당 주 강의 주제(예: 얼굴 각도)를 작가 스타일로 | 규칙 검증 6단계. 모작 대비 응용이 같거나 비슷해야 전이가 일어남 |
| 자유 그림(스타일 목표 없음) | 10% | 낙서/좋아하는 것 | Drawabox 50% 규칙의 축소판. 완전 면제는 권장하지 않음 |

운용 규칙 [제안]:
- 한 세션 안에서 **순서는 기초 → 모작 → 응용**(몸풀기 → 관찰 → 적용).
- 모작:응용은 **1:1 이상**을 유지. 모작이 응용보다 많아지면 경고.
- 초반 2~3주는 규칙서를 채우는 시기라 모작 35% / 응용 15%로 시작, 규칙서 v1이 완성되면 25/25로 이동.
- 강의 과제가 이미 "작가 스타일로 수행"이므로 그 과제는 응용작으로도 계산한다(중복 집계 방지).

## 3. 흔한 실패 유형과 점검법

| # | 실패 유형 | 증상 | 점검 / 대응 |
|---|---|---|---|
| 1 | 디테일부터 따라 그리기 | 눈·머리카락은 닮았는데 전체 비율이 어긋남 | 3분할 보조선 + 원본 겹쳐 비교 [Clip Studio]. 파트 비율 수치로 확인 |
| 2 | 복제만 하고 이유를 묻지 않음 | 몇 장을 그려도 새 그림은 못 그림 | 모작마다 "왜 여기 선이 굵은가/왜 이 색인가" 질문 3개를 기록 [seaglassdraws, Proko]. 응용작 없으면 모작 불인정 |
| 3 | 모작에서 끝남 (전이 실패) | 모작은 되는데 오리지널 구도에서 무너짐 | 6단계: 원본에 없는 포즈 1장. 같은 작가처럼 보이는지 겹쳐 놓고 확인 |
| 4 | 스포이트/트레이싱 의존 | 색·선 감각이 안 늘음 | 눈대중 색 맞추기 후 비교 [seaglassdraws]. 트레이싱은 비율 확인 오버레이 용도로만 |
| 5 | 한 장의 우연을 규칙으로 오인 | 특정 작품 한정 특징을 일반화 | 레퍼런스 3장 이상에서 반복되는 것만 규칙으로 승격 [형식분석: 여러 작품 비교] |
| 6 | 너무 어려운 원본 선택 | 좌절, 완성 못함 | 선화/단순 작품부터, 한 번에 한 측면만 [Proko] |
| 7 | 기초 생략 -> 스타일 모방이 얕음 | 형태가 뒤틀려도 원인을 모름 | 스타일은 "정확한 형태 위의 변형"이므로 기초 드릴을 주 40% 유지. Drawabox처럼 기초는 이후 모든 그림의 토대 [Drawabox 요약] |
| 8 | 스타일 규칙이 너무 많아 한꺼번에 적용 | 그림이 굳음 | PLAN의 "한 번에 고칠 점 2개" 유지. 규칙 우선순위(비율>선>명암>색) 부여 [제안] |
| 9 | 출처 미표기 / 작품을 자작으로 공개 | 윤리·저작권 문제 | 모작 파일명에 작가·링크 기록, 공개 금지 또는 "모작" 명시 [seaglassdraws] |
| 10 | 자유 그림 없음 -> 소진 | 연습이 의무가 됨 | 자유 그림 10% 확보 [Drawabox 50% 규칙 취지] |

## 4. RULEBOOK.md / PLAN.md 개선 제안 (구체적 수정안)

현재 RULEBOOK은 항목은 좋으나 **"측정 방법"과 "근거(어느 레퍼런스에서 확인했나)"가 없고**, PLAN은 **모작/응용/기초 비율과 단계 구분**이 없다.

### 4-1. RULEBOOK.md 수정안

(A) 머리말에 증거 규칙 추가. 기존 6~7행 아래에 삽입:
```
- 규칙 승격 조건: 레퍼런스 3장 이상에서 반복 확인된 것만 "확정"으로 적는다. 1~2장이면 "가설"로 표시.
- 각 항목은 `값 | 확신도(확정/가설) | 근거 이미지(reference/파일명)` 형식으로 쓴다.
- 비율은 보조선 위에서 직접 잰 값. 눈대중 금지.
```
