# 그림 연습 저장소

oridays 강의를 따라가면서 특정 작가 그림체를 학습하기 위한 연습 기록소입니다.
Claude와 세션을 반복하며 계획을 계속 업그레이드하는 것이 목적입니다.

## Claude에게 세션을 시작할 때 주는 지시 (복사해서 쓰세요)

> `PLAN.md`를 읽고 현재 버전과 "다음 세션 할 일"을 확인해. 그다음 `log/`의 최신 기록과
> `style/RULEBOOK.md`를 읽어. 내가 올리는 그림/정보를 반영해서 작업하고, 끝나면
> `PLAN.md`의 버전을 올리고 변경 이력을 적은 뒤 커밋·푸시해.

이 한 줄만 주면 Claude가 저장소 상태를 기준으로 이어서 작업합니다.

## 구조

| 경로 | 역할 |
|---|---|
| `PLAN.md` | 전체 계획. 버전 번호와 변경 이력이 있음. 매 세션 끝에 갱신 |
| `style/RULEBOOK.md` | 목표 작가의 그림체 규칙서. 모작할 때마다 수정 |
| `lectures/` | oridays 강의 회차별 체크리스트 |
| `log/` | 날짜별 연습 기록과 Claude 피드백 |
| `feedback/` | 그림 파일(사진)과 그에 대한 피드백 |
| `reference/` | 작가 레퍼런스 이미지 모음 |

## 세션 유형

- **분석 세션**: 작가 그림을 올리고 `style/RULEBOOK.md`를 채우거나 수정
- **강의 세션**: 들은 회차를 요약해 주면 `lectures/`에 체크리스트 생성
- **피드백 세션**: 과제 그림을 올리면 체크리스트와 규칙서 기준으로 피드백, `log/`에 기록
- **주간 정리 세션**: 한 주 기록을 모아 `PLAN.md` 갱신
